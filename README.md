# RMR Coat Studio

Web tool for RMR Performance. A customer photographs a metal part (3–4 sides), previews powder coat or Cerakote on a 3D stand-in, and gets a ballpark price.

```bash
npm install
npm run dev
```

Opens at `http://127.0.0.1:5173`. Shop rates are sample numbers until you edit them in the page (saved in the browser). Four photos are not a metrology scan; final quotes still come from the shop.
